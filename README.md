- ## [Spotter – AI Drone Crowd Safety (VOLO)](https://totallynotspying.ca)
Tags: *#computer vision #AI/ML #cloud #startup*

A live crowd-safety platform for outdoor events, built with a 3-person team. Drone video streams into a YOLO + ByteTrack detection worker that counts people in each zone and flags anyone who steps into a closed area. Supervisors get an alert with a snapshot and choose to dispatch or dismiss. In head-to-head tests against Google Video Intelligence and Roboflow, Spotter was the only product to raise both crowding and breach alerts on a live feed, with breach alerts in about 0.6 s (Python, YOLO, ByteTrack, OpenCV, FastAPI, React, TypeScript, PostgreSQL, Docker, Terraform, AWS ECS Fargate, S3, CloudFront).

[Live app](https://totallynotspying.ca)

- ## [RollCall](https://github.com/Muaawiz1/RollCall)
Tags: *#full-stack web app #cloud infrastructure #IaC*

A classroom presentation manager with randomized team draws and two-phase presentation and Q&A timers. The server owns session and timer state, so a browser refresh never resets a running session, and PostgreSQL row and advisory locks keep draws consistent under concurrent requests. I owned the backend and the AWS infrastructure. Terraform defines two deployment paths: ECS Fargate behind an ALB, and a lower-cost Lambda + API Gateway alternative. CI runs pytest, Vitest and Terraform validation, and tagged releases deploy through GitHub Actions with OIDC (FastAPI, SQLModel, PostgreSQL, Supabase Auth, React, TypeScript, Docker, Terraform, AWS).

[Docs](https://github.com/Muaawiz1/RollCall/blob/main/README.md)

- ## [FlyNext Travel Platform](https://github.com/Muaawiz1/FlyNext-Travel-Platform)
Tags: *#full-stack web app #REST API #team lead*

A full-stack flight and hotel booking platform built by a 3-person team I led. It has 47 REST API endpoints for flights, hotels, bookings, itineraries and notifications, uses live flight data from the AFS API, and generates PDF itineraries. Includes JWT auth with bcrypt hashing and a 6-model PostgreSQL schema with Prisma migrations, deployed with Docker Compose and an Nginx reverse proxy on AWS EC2 (Next.js, React, TypeScript, Tailwind CSS, PostgreSQL, Prisma, Docker, Nginx, AWS EC2).

[Docs](https://github.com/Muaawiz1/FlyNext-Travel-Platform/blob/main/README.md)

- ## [Predictive Survey Classifier](https://github.com/Muaawiz1/Predictive-Survey-Classifier)
Tags: *#machine learning #data science*

A 3-class ML pipeline that predicts which famous painting a survey respondent is describing from structured answers and free text. A weighted ensemble pairs Bernoulli Naive Bayes on bag-of-words text with a Random Forest on engineered structured features. It reaches 87.9% respondent-grouped CV accuracy, with GroupKFold used to prevent data leakage (Python, scikit-learn, pandas, NumPy, Jupyter).

[Docs](https://github.com/Muaawiz1/Predictive-Survey-Classifier/blob/main/README.md)
