- ## [FlyNext Travel Platform](https://github.com/Muaawiz1/FlyNext-Travel-Platform)
Tags: *#full-stack web app #REST API #team lead*

A full-stack travel booking platform built with a 3-person team I led, with 45+ REST API endpoints for flights, hotels, bookings and itineraries that integrate third-party booking services. Includes JWT auth with bcrypt hashing, a 6-model PostgreSQL schema with Prisma migrations, and deployment with Docker Compose and Nginx on AWS EC2 (TypeScript, Next.js, Node.js, PostgreSQL, Prisma, Docker, AWS EC2).

[Docs](https://github.com/Muaawiz1/FlyNext-Travel-Platform/blob/main/README.md)

---

- ## [RollCall](https://github.com/Muaawiz1/RollCall)
Tags: *#full-stack web app #serverless #IaC*

A full-stack presentation manager with persistent timers and randomized team selection, with infrastructure defined in Terraform and deployed on AWS ECS and Lambda (FastAPI, PostgreSQL, React, TypeScript, Docker, Terraform, AWS).

[Docs](https://github.com/Muaawiz1/RollCall/blob/main/README.md)

- ## VOLO – AI Drone Surveillance
Tags: *#startup #computer vision #cloud*

An early-stage startup I'm leading. The prototype backend streams live drone video into YOLO/OpenCV workers for incident detection, running on Kubernetes, AWS Fargate and Redis, and covered by pytest unit tests (Python, Redis, Kubernetes, AWS Fargate, YOLO, OpenCV, pytest).

- ## [Fitness App](https://github.com/Muaawiz1/Fitness-App)
Tags: *#clean architecture #REST API #testing*

A Java fitness and nutrition app built with Clean Architecture, featuring a calorie counter, meal planning and workout search. Integrates 3 external REST APIs (Edamam, ExerciseDB, Fitness Calculator) behind data-access interfaces, with JUnit 5 tests that isolate business logic from I/O (Java, Swing, JUnit, REST APIs).

[Docs](https://github.com/Muaawiz1/Fitness-App/blob/main/README.md)

Tags: *#machine learning #data science*

A 3-class ML classifier that predicts which famous painting a survey respondent is describing from structured survey data and free-text responses, reaching 87.9% grouped-CV accuracy (Python, Jupyter Notebook).
